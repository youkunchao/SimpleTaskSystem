# 启蒙星（KidStar）- 幼儿识字启蒙教育平台 - 产品需求文档

## Overview
- **Summary**: 一款面向 3-7 岁幼儿的识字启蒙教育平台，提供汉字识字、英语启蒙、数学思维、绘本点读等互动式学习内容，通过游戏化体验和艾宾浩斯间隔重复算法帮助幼儿高效学习，同时支持家长账号管理多子女学习进度。
- **Purpose**: 让幼儿在轻松愉快的游戏化环境中完成识字、英语和数学启蒙，帮助家长科学跟踪孩子学习进度并制定个性化复习计划。
- **Target Users**: 3-7 岁幼儿（主要使用者）、幼儿家长（管理者/陪伴者）

## Goals
- 提供系统化、分级递进的汉字、英语、数学启蒙课程
- 通过游戏化交互（点击、拖拽、点读）让幼儿主动学习
- 基于艾宾浩斯遗忘曲线实现个性化复习路径推荐
- 支持家长注册登录并管理多个子女账号
- 可视化学习进度追踪与奖励激励体系

## Non-Goals
- 不涉及学校管理、教师端或班级授课场景
- 不提供付费订阅/支付系统（免费内容）
- 不做社交功能与社区讨论
- 不做实时音视频互动课程
- 不做离线原生 App（仅 Web 端）

## Background & Context
- 3-7 岁是幼儿语言和认知发展关键期，科学的分级内容与间隔重复能显著提升学习效果
- 家长需要便捷地管理多个孩子的学习并获得进度反馈
- 平台采用前后端分离架构：React + Vite 前端，Node.js + Express + SQLite 后端，JWT 鉴权

## Functional Requirements

### 账号与权限
- **FR-1**: 家长可注册账号（用户名+密码）并登录/登出
- **FR-2**: 家长账号下可创建、查看、删除多个孩子档案（姓名、年龄、头像）
- **FR-3**: 家长可选择当前活跃孩子进行学习
- **FR-4**: 学习内容与进度按孩子隔离存储

### 分级课程体系
- **FR-5**: 汉字课程按难度分级（L1 入门、L2 基础、L3 进阶、L4 提高），每级含多个字卡
- **FR-6**: 英语单词按主题分级（动物、食物、颜色、数字、家庭）
- **FR-7**: 数学思维按能力分级（数与量、比较、加减、图形）
- **FR-8**: 绘本按难度分级（亲子共读、自主阅读）

### 互动式学习模块
- **FR-9**: 汉字认知——展示汉字、拼音、笔顺动画、组词、象形图，支持发音
- **FR-10**: 单词记忆——展示英文单词、中文释义、配图、发音，支持跟读测试
- **FR-11**: 数学小游戏——数字比大小、加减法运算、图形识别等互动游戏
- **FR-12**: 绘本点读——展示绘本页面，点击文字/图片可触发朗读，支持翻页

### 学习进度追踪
- **FR-13**: 记录每个孩子在各模块的学习次数、正确率、学习时长
- **FR-14**: 家长端可视化展示学习进度（按日/周统计）
- **FR-15**: 记录已掌握和未掌握的知识点

### 个性化复习路径（艾宾浩斯间隔重复）
- **FR-16**: 对已学知识点按艾宾浩斯间隔（1天、2天、4天、7天、15天）安排复习
- **FR-17**: 首页推荐今日待复习内容，答错则重置间隔，答对则延长间隔
- **FR-18**: 根据孩子薄弱项生成个性化复习清单

### 奖励激励系统
- **FR-19**: 完成学习任务获得星星奖励
- **FR-20**: 星星可兑换虚拟徽章/成就
- **FR-21**: 展示孩子的学习连续打卡天数

## Non-Functional Requirements
- **NFR-1**: 界面色彩明亮活泼，字体大，适合幼儿操作，无复杂操作
- **NFR-2**: 页面交互响应延迟 < 500ms
- **NFR-3**: 数据持久化存储，服务重启不丢失
- **NFR-4**: 密码哈希存储，JWT 鉴权，接口鉴权保护
- **NFR-5**: 兼容主流浏览器（Chrome、Firefox、Edge 最新版）
- **NFR-6**: 代码结构清晰，前后端分离，可独立运行

## Constraints
- **Technical**: 前端 React + Vite + TailwindCSS；后端 Node.js + Express + better-sqlite3；JWT 鉴权；RESTful API
- **Business**: 内容为内置示范数据，无需 CMS 后台动态管理
- **Dependencies**: 依赖 Node.js 运行环境；字体发音使用 Web Speech API（浏览器内置）

## Assumptions
- 运行环境已安装 Node.js 18+
- 浏览器支持 Web Speech API（现代浏览器均支持）
- 单服务器部署，无分布式需求
- 内容数据以 JSON 种子数据形式内置

## Acceptance Criteria

### AC-1: 家长注册与登录
- **Type**: `rule`
- **Given**: 未登录状态下访问登录页
- **When**: 用户填写有效用户名密码点击注册，再用该账号登录
- **Then**: 注册成功并跳转登录，登录成功后获得 JWT 并进入首页
- **Pass Condition**: 能完成注册→登录流程，受保护接口返回数据
- **Evidence**: 浏览器操作演示 + 后端日志

### AC-2: 多孩子账号管理
- **Type**: `rule`
- **Given**: 已登录家长账号
- **When**: 创建 2 个孩子档案，切换活跃孩子后进行学习
- **Then**: 两个孩子的学习数据相互隔离
- **Pass Condition**: 切换孩子后进度数据随之切换
- **Evidence**: 数据库查询与界面显示

### AC-3: 分级课程体系展示
- **Type**: `rule`
- **Given**: 已选择活跃孩子
- **When**: 进入汉字/英语/数学/绘本模块
- **Then**: 显示对应分级课程列表，可选择级别进入学习
- **Pass Condition**: 四个模块均有分级内容可访问
- **Evidence**: 界面截图

### AC-4: 汉字认知互动
- **Type**: `rule`
- **Given**: 进入汉字学习页
- **When**: 浏览汉字、点击发音、完成认字测试
- **Then**: 汉字展示拼音/笔顺/组词，可发音，测试结果记录进度
- **Pass Condition**: 发音正常，测试结果被记录
- **Evidence**: 界面交互 + 进度接口返回

### AC-5: 英语单词记忆
- **Type**: `rule`
- **Given**: 进入英语学习页
- **When**: 浏览单词、听发音、完成选词测试
- **Then**: 单词展示释义/配图/发音，测试正确率被记录
- **Pass Condition**: 发音与测试功能正常，进度更新
- **Evidence**: 界面交互

### AC-6: 数学小游戏
- **Type**: `rule`
- **Given**: 进入数学模块
- **When**: 完成比大小/加减法/图形识别游戏
- **Then**: 题目随机生成，答题有即时反馈，得分被记录
- **Pass Condition**: 数学游戏可正常游玩并记录得分
- **Evidence**: 游戏过程 + 得分记录

### AC-7: 绘本点读
- **Type**: `rule`
- **Given**: 进入绘本模块
- **When**: 选择绘本、翻页、点击文字/图片
- **Then**: 绘本可翻页，点击触发朗读语音
- **Pass Condition**: 翻页与点读功能正常
- **Evidence**: 界面交互

### AC-8: 学习进度追踪
- **Type**: `rule`
- **Given**: 孩子完成若干学习任务
- **When**: 家长进入进度报告页
- **Then**: 显示学习次数、正确率、时长统计图表
- **Pass Condition**: 统计数据与实际学习记录一致
- **Evidence**: 进度页显示

### AC-9: 艾宾浩斯复习推荐
- **Type**: `rule`
- **Given**: 孩子已学习部分内容
- **When**: 访问首页
- **Then**: 显示今日待复习清单，包含到期复习项
- **Pass Condition**: 复习清单基于间隔算法生成，答错重置间隔
- **Evidence**: 复习推荐列表 + 间隔字段变更

### AC-10: 奖励激励系统
- **Type**: `rule`
- **Given**: 孩子完成学习任务
- **When**: 获得星星并查看徽章/连续打卡
- **Then**: 星星数量增加，可查看已解锁徽章和连续打卡天数
- **Pass Condition**: 星星、徽章、打卡数据正确累加与展示
- **Evidence**: 奖励页显示

### AC-11: 幼儿友好界面
- **Type**: `rubric`
- **Dimension**: 界面儿童友好度
- **Scale**: 1-5
- **Anchors**: 1 = 界面成人化、字小、操作复杂；3 = 基本可读但交互偏复杂；5 = 大字体、明亮色彩、图标化、操作极简
- **Pass Threshold**: >= 4
- **Evidence**: 界面截图评估

### AC-12: 系统响应性能
- **Type**: `rubric`
- **Dimension**: 交互响应速度
- **Scale**: 1-5
- **Anchors**: 1 = 卡顿明显，>2s；3 = 偶有延迟，1-2s；5 = 流畅，<500ms
- **Pass Threshold**: >= 4
- **Evidence**: 操作体感
