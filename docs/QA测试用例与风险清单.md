# 启蒙星 · 测试用例与风险清单

> 覆盖范围：幼儿识字启蒙教育平台（Web 前端 + 后端接口）
> 拆解粒度：按钮 / 输入框 / 状态 / 提示文案
> 用例总数：**212 条**（功能用例 176 + 端到端串联 18 + 破坏性 18）
> 优先级定义：
> - **P0**：核心主流程与阻断项，失败则不可上线
> - **P1**：重要功能、常见分支与异常，影响体验但不阻断
> - **P2**：边界值、次要细节、文案与视觉

# 五、自查：遗漏风险点

| 编号 | 风险点 | 说明 | 等级 |
|---|---|---|---|
| R-01 | **JWT_SECRET 未设置** | 服务启动日志明确提示使用开发用密钥；生产环境必须配置，否则 token 可被伪造 | **P0（阻断上线）** |
| R-02 | **数据层跑在实验性 `node:sqlite`** | better-sqlite3 原生绑定缺失（node v24 无预编译包），已回退到 Node 内置 `node:sqlite`（ExperimentalWarning）。生产库不应依赖实验性 API | **P0（阻断上线）** |
| R-03 | 大量接口异常被静默吞掉 | 多处 `catch(() => {})`（首页复习/奖励、进度提交等），失败时用户无感知、数据可能丢失 | P1 |
| R-04 | 添加孩子姓名为空无提示 | `handleAdd` 中 `if (!newName) return;` 直接返回，界面无任何反馈 | P1 |
| R-05 | 未验证真机与横屏 | 汉字/英语学习页有 `useLandscape` 横屏适配，仅桌面浏览器验证过 | P1 |
| R-06 | 未验证语音实际听感 | 预合成 8664 条音频与 Web Speech 回退的听感、音色、断句未做人工试听 | P1 |
| R-07 | 仓库体积 | 8664 个 mp3 已入库（约 123MB），影响 clone/部署效率；建议 Git LFS 或 CDN | P1 |
| R-08 | CORS 仅允许 localhost | 生产需按域名配置 `CORS_ORIGIN`，否则全部 403 | P1 |
| R-09 | 无密码找回/修改密码 | 只有注册与登录 | P2 |
| R-10 | 登录限流 10 次/分钟 | 学校/家庭共网场景可能误伤正常用户 | P2 |
| R-11 | 依赖本机时间 | 连续打卡、复习间隔按本机日期计算，改系统时间可绕过 | P2 |
| R-12 | 无障碍/大字体未验证 | 未验证超大字号、读屏、对比度（除已修复的黄底白字） | P2 |

# 六、P0 阻断缺陷清单（存在即不可上线）

| 编号 | 缺陷 | 影响 | 现状 | 修复建议 |
|---|---|---|---|---|
