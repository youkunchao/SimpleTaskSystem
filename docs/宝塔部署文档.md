# 启蒙星（KidStar）宝塔面板部署文档（详细版）

本文面向使用 **宝塔面板（BaoTa / aaPanel）** 运维服务器的同学，手把手说明如何把「启蒙星」幼儿识字启蒙平台部署上线。前端 React/Vite，后端 Node/Express + SQLite（单文件数据库，无需额外装数据库）。

> 目标形态：**宝塔建站（域名 + HTTPS）→ Nginx 托管前端静态资源 → 反向代理 `/api` 到本地 Node 后端**，Node 进程由宝塔 Node 项目（PM2）守护。后端 `tts-audio/` 离线音频随服务器一同部署。

---

## 一、环境准备（宝塔面板）

### 1.1 安装宝塔面板
- 官方：`https://www.bt.cn`（Linux 版，支持 CentOS / Ubuntu / Debian）。
- 安装完成后登录面板，记下 **面板端口 / 安全入口 / 用户名密码**。
- 首次进入会提示安装 LNMP/LAMP 套件，**至少勾选 `Nginx`**（本方案不需要 MySQL，因为用 SQLite）。

### 1.2 安装所需运行环境（软件商店）
进入 **软件商店**，安装：
| 软件 | 用途 | 版本建议 |
|---|---|---|
| **Node.js 版本管理器**（或 "Node.js 项目 / PM2 管理器"） | 运行后端、构建前端 | 安装后选 **Node 18 LTS 或更高** |
| **Nginx** | 反向代理 + 静态托管 + SSL | 任意稳定版 |
| **Python 项目管理器**（可选） | 仅当你要在服务器上**重新生成 TTS 音频**时才需要 | Python 3.9+ |

> 说明：`better-sqlite3` 是原生模块，npm 安装时会拉取对应 Node 版本的预编译二进制；只要 Node 版本与 `npm install` 时一致，通常无需手动编译。若安装报错（缺少预编译包），在宝塔**终端**执行 `yum install -y gcc make gcc-c++`(CentOS) / `apt install -y build-essential`(Debian/Ubuntu) 后再装。

### 1.3 放行端口
- 进入 **安全** 页面：放行 `80`、`443`（网站用）。
- 后端端口 `3001`：**建议只对内网开放**（本方案经 Nginx 反代，公网无需直连 3001）。可在 **安全** 中把 3001 设为不对外放行，或在云厂商安全组仅开放 80/443。

---

## 二、获取项目代码

推荐把**整个仓库**上传到服务器，保持 `server/` 与 `client/` 的相对目录关系（后端会按 `../../client/dist` 寻找前端构建产物）。

### 方式 A：宝塔文件管理器上传
1. 在本地把项目打包为 `kidstar.zip`（排除 `node_modules/`、`server/data/*.db`、`tts-audio/` 可选，减小体积）。
2. 宝塔 **文件** → 进入 `/www/wwwroot/` → 上传 `kidstar.zip` → 解压到 `/www/wwwroot/kidstar/`。

### 方式 B：宝塔终端 git 拉取
```bash
cd /www/wwwroot
git clone <repo-url> kidstar
cd kidstar
```
> 若用方式 A 上传时排除了 `tts-audio/`，请单独把本地已生成的 `server/tts-audio/`（约 1 万+ mp3）上传到 `server/tts-audio/`，否则朗读会回退 Web Speech。

---

## 三、构建前端（client）

1. 宝塔 **软件商店 → Node.js 版本管理器** → 切换到项目所用 Node 版本。
2. 打开 **终端**：
```bash
cd /www/wwwroot/kidstar/client
npm install
npm run build          # 产物输出到 client/dist
```
构建成功后会生成 `/www/wwwroot/kidstar/client/dist`。

---

## 四、部署后端（宝塔 Node 项目 / PM2）

### 4.1 安装后端依赖
```bash
cd /www/wwwroot/kidstar/server
npm install            # 务必在"项目所用 Node 版本"下执行，保证原生模块匹配
```
- 首次启动会自动建库并写入种子数据（`server/data/kidstar.db`），已有数据不重复写入。
- 确认 `server/tts-audio/` 已就位。

### 4.2 在宝塔添加 Node 项目
1. **软件商店 → Node.js 版本管理器（或 Node.js 项目）→ 添加项目**：
   - 项目名称：`kidstar-api`
   - 项目目录：`/www/wwwroot/kidstar/server`
   - 启动文件 / 启动命令：选 `src/index.js`（也可填 `npm start`）
   - Node 版本：选择上面已切到的 18+ 版本
   - 运行端口：`3001`
   - 运行用户：`www`（默认）
2. **设置环境变量**（宝塔项目配置里的"环境变量"，每行 `KEY=VALUE`）：
   ```
   NODE_ENV=production
   PORT=3001
   JWT_SECRET=<至少32位随机字符串，例如 openssl rand -hex 32 的输出>
   CORS_ORIGIN=https://你的域名,capacitor://localhost,http://localhost
   ```
   > ⚠️ 生产环境 **必须** 设置 `JWT_SECRET`（≥32 位），否则后端启动即报错拒绝运行。`CORS_ORIGIN` 填你的前端域名（即使同源反代也建议填上，避免跨站调用）。
   >
   > **若后端要供手机 App（Capacitor）使用**，必须额外加上 App 来源 `capacitor://localhost` 与 `http://localhost`（逗号分隔）。App 来源是 `capacitor://localhost`，**不会**被后端的 localhost 自动放行规则覆盖，漏配会导致 App 内所有接口返回 403。详见 `docs/App打包(Capacitor).md`。
3. 点击 **启动**；在 "项目日志" 里看到 `🚀 启蒙星后端已启动: http://localhost:3001` 即成功。
4. 验证：`curl http://127.0.0.1:3001/api/health`（或任意公开接口）应返回正常 JSON。

> 宝塔 Node 项目基于 PM2，进程崩溃会自动重启；重启服务器后也会随面板自启（勾选"开机启动"）。

## 五、建站 + 反向代理 + SSL（宝塔网站）

### 5.1 添加站点
1. **网站 → 添加站点**：
   - 域名：填写你的域名（需事先解析 A 记录到本机 IP）
   - 根目录：`/www/wwwroot/kidstar/client/dist`（直接让 Nginx 托管前端静态产物，性能更好）
   - PHP 版本：纯静态 / 无
2. 进入该站点 **设置 → 伪静态**，填入 SPA 回退规则（避免刷新 / 深链 404）：
   ```
   try_files $uri $uri/ /index.html;
   ```

### 5.2 反向代理（关键）
1. 站点 **设置 → 反向代理 → 添加反向代理**：
   - 代理名称：`kidstar-api`
   - 目标 URL：`http://127.0.0.1:3001`
   - 发送域名：`$host`
2. 但默认会把所有请求都代理到后端。我们需要 **仅代理接口**，静态资源由 Nginx 直接返回。两种做法：

   **做法 A（推荐，精确代理）**：编辑站点 **配置文件**，把默认的全量反代改成只代理 `/api`：
   ```nginx
   location ^~ /api/ {
       proxy_pass http://127.0.0.1:3001;
       proxy_set_header Host $host;
       proxy_set_header X-Real-IP $remote_addr;
       proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
       proxy_set_header X-Forwarded-Proto $scheme;
   }
   ```
   其他路径（`/`、`/assets/*`）由 Nginx 从 `client/dist` 直接返回（配合上面的 `try_files`）。

   **做法 B（最简，全量反代）**：保留默认反代（代理 `/` 到 3001），此时后端会自己托管 `client/dist` 并做 SPA 回退，**站点根目录填什么无所谓**。缺点是静态资源也走 Node，性能略低，但最省事。

> 前端 `api.js` 使用相对基址 `/api`，因此无论哪种做法都无需改代码。

### 5.3 配置 HTTPS（SSL）
1. 站点 **设置 → SSL → Let's Encrypt** → 申请免费证书（需域名已解析且 80 端口可访问）→ 部署。
2. 开启 **强制 HTTPS**。
3. 完成后访问 `https://你的域名/` 即可使用，接口与音频均走同域 HTTPS，无混合内容问题。

## 六、防火墙与安全加固

- **宝塔 → 安全**：仅放行 `80` / `443`；`3001` 不对外网开放（本方案经本地反代，后端只需监听 127.0.0.1 即可；当前代码 `app.listen(PORT)` 默认监听全部网卡，公网是否可达取决于防火墙，请确保云安全组 / 宝塔端口规则未放行 3001）。
- **JWT_SECRET** 务必为强随机串，切勿使用弱口令或留空（生产留空会启动失败，已做防护）。
- **CORS_ORIGIN** 仅放行业务域名。
- 面板本身：修改默认面板端口、开启面板 SSL、设置安全入口与强密码。

## 七、TTS 离线音频（重要）

- 目录 `server/tts-audio/`（含 `manifest.json` + 上万 mp3）**必须整目录部署**，否则 `/api/tts` 返回 404，前端自动回退 Web Speech（仍可发声，但非晓晓/晓伊神经网络语音）。
- 当前版本音频已随仓库/本地生成（约 **10602** 个 mp3，manifest 孤儿 0），直接上传即可。
- **如需在服务器重新生成音频**（内容更新后）：
  1. 宝塔 **Python 项目管理器** 安装 Python 3 + `pip install edge-tts`；
  2. 后端需先在 3001 运行，然后：
     ```bash
     cd /www/wwwroot/kidstar/server
     node scripts/gen_phrases.mjs
     python scripts/gen_tts.py            # 已存在文件自动跳过（断点续跑）
     python scripts/gen_tts_orphans.py    # 补齐 manifest 孤儿
     ```
  3. ⚠️ 离线合成依赖网络可达微软 TTS。部分国内机房 / 受限网络会拦截非浏览器客户端，如遇此情况，**建议在本地可联网机器生成 `tts-audio/` 后，再上传覆盖服务器对应目录**。
- 数学**测验题面**为动态朗读，本就未预合成，运行时走浏览器/系统兜底，无需离线生成。

## 八、数据备份与回滚

### 8.1 备份
- 业务数据全部在 `server/data/`（SQLite：`kidstar.db` 及 `-wal`/`-shm`）。
- 宝塔 **计划任务 → 备份文件**：新增任务，目标目录选 `/www/wwwroot/kidstar/server/data`，周期（如每天）备份到本地或云存储。
- 音频为静态资源，可随代码版本管理，不必高频单独备份。

### 8.2 回滚
- 保留上一个可构建版本；回滚代码 → 重启 Node 项目即可。
- 数据库向后兼容、种子幂等，**回滚代码不影响既有用户数据**（涉及表结构变更才需先备份再操作）。

## 九、升级 / 重新部署流程

1. 拉取 / 上传新代码到 `/www/wwwroot/kidstar/`；
2. 若后端依赖变化：`cd server && npm install`；
3. 前端重新构建：`cd client && npm install && npm run build`；
4. 宝塔 **Node 项目 → 重启** `kidstar-api`；
5. 若更新了内容并重新生成了 `tts-audio/`，覆盖服务器 `server/tts-audio/` 后重启；
6. 验证首页与朗读是否正常。

- [ ] 前端 `npm run build` 成功，`client/dist` 存在
- [ ] 后端 `npm install` 在对应 Node 版本下完成
- [ ] Node 项目环境变量：`NODE_ENV=production`、`JWT_SECRET`（≥32 位）、`CORS_ORIGIN=https://域名`（供 App 时须含 `capacitor://localhost,http://localhost`）
- [ ] Node 项目已启动，日志无 `❌ 启动失败`
- [ ] 宝塔站点根目录指向 `client/dist`，伪静态含 `try_files ... /index.html`
- [ ] 仅 `/api` 反代到 `127.0.0.1:3001`（或全量反代）
- [ ] SSL 已部署并强制 HTTPS
- [ ] 宝塔 / 云安全组 仅放行 80/443，3001 不对外
- [ ] `server/data/` 已配置定时备份

## 十一、常见问题与排错

| 现象 | 原因 | 处理 |
|---|---|---|
| Node 项目启动失败，日志报 `better-sqlite3` 原生模块错误 | Node 版本与 `npm install` 时不一致 / 无预编译包 | 在宝塔切换并统一 Node 版本后重装；或装 `gcc make`（CentOS）/ `build-essential`（Debian）后重装 |
| 启动即 `❌ 启动失败：生产环境必须设置 JWT_SECRET` | 生产缺密钥 | 在 Node 项目环境变量补 `JWT_SECRET`（≥32 位） |
| 访问网站 502 Bad Gateway | Node 项目未启动 / 端口错 / 3001 被墙 | 确认 Node 项目运行中、`PORT=3001`、反代目标 `127.0.0.1:3001` 可达 |
| 接口 403 / 跨域报错 | `CORS_ORIGIN` 未含前端域名 | 修正 Node 项目环境变量 `CORS_ORIGIN` |
| 手机 App 内接口全部 403（`{"error":"来源不被允许"}`） | App 来源 `capacitor://localhost` 未放行 | 环境变量 `CORS_ORIGIN` 追加 `capacitor://localhost,http://localhost`，重启 Node 项目 |
| 页面刷新 / 深链 404 | 未配置 SPA 回退 | 站点伪静态加 `try_files $uri $uri/ /index.html;` |
| 朗读变成机械音 | `tts-audio/` 未部署或 404 | 上传整目录 `server/tts-audio/` 并重启 |
| 用户进度丢失 | 误删 `server/data/` | 从宝塔备份恢复 `data/` |
| 宝塔"Node 项目"找不到 `src/index.js` | 项目目录指错 | 项目目录应为 `server/`，启动文件 `src/index.js`（相对 server） |
