# 启蒙星（KidStar）部署文档

本文说明如何把「启蒙星」幼儿识字启蒙教育平台从源码部署到生产环境。前端为 React/Vite，后端为 Node/Express + SQLite，二者可**单服务器同源部署**（最简），也可前后端分离 + Nginx 部署。

---

## 1. 部署架构

```
浏览器 ──(同源 80/443)──> [Node 后端 :3001]
                            ├─ /api/*        REST 接口（Express）
                            ├─ /api/tts      POST 返回离线 MP3（server/tts-audio/）
                            └─ /*           生产模式下托管 client/dist（SPA 静态资源）
```

- 生产模式后端会**直接托管前端构建产物**（`client/dist`），API 与页面同源，无需额外 CORS / 静态服务器。
- 若选择"分离部署"，前端由 Nginx 托管，仅把 `/api` 与 `/api/tts` 反向代理到后端即可。

---

## 2. 环境要求

| 组件 | 要求 |
|---|---|
| 操作系统 | Linux / Windows Server（本文示例以 Linux 为主） |
| Node.js | 18 LTS 或更高（需与 `better-sqlite3` 预编译二进制匹配） |
| npm | 随 Node 自带 |
| 磁盘 | 后端含 `tts-audio/`（约 1 万+ 个 mp3，数百 MB 级），预留足够空间 |
| （可选）Python 3 | 仅当你需要**重新生成 TTS 音频**时，需 `edge-tts`（`pip install edge-tts`） |
| 进程守护 | `pm2` 或 `systemd`（推荐） |

> `better-sqlite3` 为原生模块，`npm install` 时会拉取对应平台的预编译二进制；若平台无预编译包则需本地编译（需 python + 构建工具链）。

## 3. 方式一：单服务器部署（推荐）

### 3.1 获取代码
```bash
git clone <repo-url>  kidstar
cd kidstar
```

### 3.2 构建前端
```bash
cd client
npm install
npm run build          # 产物输出到 client/dist
```

### 3.3 安装并启动后端
```bash
cd ../server
npm install
# 设置生产环境变量后启动
NODE_ENV=production \
PORT=3001 \
JWT_SECRET="<至少32位随机字符串>" \
CORS_ORIGIN="https://your-domain.com" \
npm start
```
后端启动后会：
1. 校验生产配置（缺 `JWT_SECRET` 直接拒绝启动）；
2. 自动建库、写入种子数据（仅首次，已有数据不重复写入）；
3. 检测到 `client/dist` 存在 → 托管前端静态资源 + SPA 回退；
4. 监听 `PORT`。

访问 `http://<server>:3001/` 即可使用（页面与接口同源）。

## 4. 方式二：前后端分离 + Nginx

### 4.1 后端（仅 API）
```bash
cd server && npm install
NODE_ENV=production PORT=3001 \
JWT_SECRET="..." \
CORS_ORIGIN="https://your-domain.com" \
npm start
```
> 此模式下若后端**未**检测到 `client/dist`，则只提供 `/api`；前端由 Nginx 托管。

### 4.2 前端静态托管 + 反向代理（Nginx 示例）
```nginx
server {
  listen 443 ssl;
  server_name your-domain.com;

  # 前端静态资源
  root /var/www/kidstar/client/dist;
  index index.html;
  location / {
    try_files $uri $uri/ /index.html;   # SPA 回退
  }

  # 接口与音频反向代理到后端
  location /api/ {
    proxy_pass http://127.0.0.1:3001;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
  }
}
```
> 注意：前端 `api.js` 使用相对基址 `/api`，因此同源部署或经 Nginx 代理均无需改代码。`CORS_ORIGIN` 仍需设为前端域名（避免接口被跨站调用）。

## 5. 环境变量清单

| 变量 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| `NODE_ENV` | 否 | `development` | 设为 `production` 启用生产校验 + 托管前端 |
| `PORT` | 否 | `3001` | 后端监听端口 |
| `JWT_SECRET` | **生产必填** | （开发自动生成本机随机密钥） | 至少 32 位随机串；**生产缺失将拒绝启动** |
| `CORS_ORIGIN` | 否（生产建议） | `http://localhost:5173,http://localhost:4173,http://localhost:3000` | 允许跨域的来源，逗号分隔 |

## 6. 数据库与数据持久化

- 数据库为单文件 SQLite：`server/data/kidstar.db`（启用 WAL，附带 `-wal` / `-shm` 文件）。
- 首次启动自动建表 + 写入**内置种子内容**（1000 汉字 / 英语 / 数学 / 绘本 / 阅读等），已有数据不会重复写入。
- 所有**用户数据**（账号、孩子档案、学习进度、徽章）都落在该库，**部署 / 迁移时必须备份 `server/data/` 目录**。
- 升级版本时：先备份 `data/`，再拉新代码重启；种子逻辑幂等，不会破坏既有数据。

## 7. TTS 音频（`tts-audio/`）部署与重生成

### 7.1 部署
- `server/tts-audio/`（含 `manifest.json` 与上万 mp3）**必须整目录随后端部署**，否则 `/api/tts` 返回 404，前端自动回退 Web Speech（仍可发声，但非晓晓/晓伊神经网络语音）。
- 当前规模：约 **10602** 个 mp3，manifest 孤儿 0。

### 7.2 内容更新后重新生成音频
当新增/修改汉字、数学等内容后，需重跑离线合成（仅更新差异，断点续跑）：
```bash
# 1) 后端必须在 3001 运行；导出当前固定文案
node server/scripts/gen_phrases.mjs

# 2) Python + edge-tts 合成（需能连通微软语音服务的网络）
pip install edge-tts
python server/scripts/gen_tts.py          # 已存在文件自动跳过

# 3) 若 manifest 出现"有 key 无文件"的孤儿，补齐：
python server/scripts/gen_tts_orphans.py
```
> ⚠️ 离线合成依赖网络可达微软 TTS。在部分受限网络下，非浏览器客户端可能被拦截；如遇此情况，请在可联网的机器上生成后，再把 `tts-audio/` 同步到生产服务器。
> 数学**测验题面**为动态朗读，本就未预合成，运行时走浏览器/系统兜底，无需离线生成。

## 8. 进程守护（以 pm2 为例）
```bash
npm install -g pm2
cd server
pm2 start "NODE_ENV=production PORT=3001 JWT_SECRET=... CORS_ORIGIN=... node src/index.js" --name kidstar-api
pm2 save && pm2 startup
```
或使用 `systemd` 单元文件管理 `npm start`。

## 9. 上线前检查清单

- [ ] `NODE_ENV=production` 已设置
- [ ] `JWT_SECRET` 已设置且 ≥32 位（否则启动即失败）
- [ ] `CORS_ORIGIN` 设为实际前端域名
- [ ] 前端已 `npm run build` 且 `client/dist` 存在（单服务器模式）
- [ ] `server/tts-audio/` 已随后端部署（音频可用）
- [ ] `server/data/` 已规划备份
- [ ] 端口（3001 / 443）防火墙已放行
- [ ] 启动日志无 `❌ 启动失败` 与 `⚠️ 未设置 JWT_SECRET`

## 10. 常见坑与排错

| 现象 | 原因 | 处理 |
|---|---|---|
| 启动即 `❌ 启动失败：生产环境必须设置 JWT_SECRET` | 生产环境缺密钥 | 设置 ≥32 位 `JWT_SECRET` |
| 接口 403 / 跨域报错 | `CORS_ORIGIN` 未包含前端域名 | 修正 `CORS_ORIGIN` |
| 朗读变成机械音 | `tts-audio/` 未部署或 404 | 同步 `tts-audio/` 目录 |
| 页面空白 / 刷新 404 | 未构建 dist 或 SPA 回退缺失 | 确认 `client/dist` 存在；Nginx 加 `try_files ... /index.html` |
| `npm install` 报原生模块错误 | `better-sqlite3` 无匹配预编译包 | 安装 Python + 构建工具链后重装，或换匹配的 Node 版本 |
| 用户进度丢失 | 误删 `server/data/` | 从备份恢复 `data/` |

---

## 11. 备份与回滚

- **备份**：定期打包 `server/data/`（SQLite 库 + WAL）。音频为静态资源，可随代码版本管理，不必单独高频备份。
- **回滚**：保留上一个可构建的代码版本；回滚代码后重启，数据库结构向后兼容（种子幂等），数据不受影响。若涉及表结构变更，请先备份再操作。
